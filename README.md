## 🛠️ Setup & Security Protocol

### 1. Backend Brain
Ensure your `backend/` environment is active and run:
```powershell
python run.py
```

### 2. Frontend Atmosphere
You **MUST** provide Clerk API keys in your `.env` for the app to function.
```bash
cd frontend
# Copy .env.example to .env and fill in your Clerk keys:
# NEXT_PUBLIC_CLERK_PUBLISHER_KEY=...
# CLERK_SECRET_KEY=...

npm install
npm run dev
```
